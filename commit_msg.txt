feat(core): implement Chunked Iterator to resolve Memory Bloat and Race Conditions

Problem
-------
In-place operations (`copy_`, `zero_`, `add_`, `sgd`) on non-contiguous tensors previously invoked `ensure_contiguous()`, triggering massive 100MB heap allocations and copying overhead. Additionally, the fallback element-wise `NDIterator` was too slow to handle modern SIMD processing.

Broadcasted tensors (where `stride == 0` but `shape > 1`) caused severe race conditions when modified in-place across multiple threads. Memory aliasing (e.g. `[3, 4]` copied to `[2, 6]`) also triggered data corruption or segmentation faults because the iterator blindly mapped linear offsets.

Finally, zero-element tensors triggered `memcpy(nullptr, nullptr, 0)` Undefined Behavior, and `A.copy_(A)` triggered overlapping memory UB. Dispatcher operations (`add_`, `sgd`) lacked hardware cross-device guards, risking CPU-to-GPU pointer dereferencing segfaults.

Fix
---
1. Chunked Iterator: Completely deprecated the element-wise `NDIterator` inner loops in `Tensor` and `Dispatcher`. Replaced it with a high-performance Chunked Iterator that dynamically scans tensor metadata to find the deepest contiguous dimension (`chunk_dim`).
2. SIMD Vectorization: Extracts 1D contiguous segments of size `chunk_size` and applies `#pragma omp simd` to the inner loop for AVX/SSE auto-vectorization. To avoid the "Scalar Trap" where `shape == 1`, `chunk_dim` logic intelligently skips dimensions until `shape > 1`.
3. Overlap Guards: Implemented `has_internal_overlap()` in Tensor to mathematically detect overlapping broadcast strides. In-place mutations of broadcasted tensors now throw `std::runtime_error`. Autograd Engine (`engine.cpp`) and Optimizers (`optimizer.hpp`) were updated to gracefully fallback to out-of-place accumulation upon detecting internal overlaps.
4. Topological Safeties: Fixed segmentation faults when copying between topological mismatches by safely decoupling `outer_shape` offsets for source and destination when their shapes diverge. Fixed Sequential Aliasing hazards by ensuring `is_aliased` considers shape discrepancies.
5. Standard Compliance: Fixed `memcpy(nullptr)` and `memset(nullptr)` UB by wrapping all standard memory transfers with `if (numel() > 0)`. Eliminated self-copying `std::memcpy` UB by short-circuiting `copy_` when `data_ptr`, `shape`, and `stride` match identically.
6. Hardware Safety: Enforced `if (a.device() != b.device())` cross-device hardware guards in `Dispatcher::add_` and `Dispatcher::sgd` to prevent CPU-to-GPU dereferencing Segmentation Faults.

Verification
------------
- Full suite: 134/134 core tests pass cleanly.
- Memory bloat on non-contiguous in-place operations is now empirically 0 MB, verified by RSS memory analyzers.
- Developed 6 specific adversarial test cases (`scratch/audit.cpp`) that explicitly trigger the Aliasing Corruption, Broadcast Safety, Shape Mismatches, and UB vulnerabilities. All tests assert safely without data corruption or crashes.
